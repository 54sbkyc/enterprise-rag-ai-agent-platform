# 功能清单

本文档用于毕业论文的系统功能设计、系统实现和答辩展示章节。

## 角色与权限

| 功能 | 管理员 | 技术员工 | 普通员工 | 说明 |
| --- | --- | --- | --- | --- |
| 登录/退出 | 支持 | 支持 | 支持 | 每次打开系统都进入登录页，不在前端持久化令牌。 |
| 查看首页总览 | 支持 | 支持 | 不支持 | 普通员工登录后直接进入问答工作台。 |
| 上传文档 | 支持 | 支持 | 不支持 | 管理角色可上传 TXT、Markdown、PDF、DOCX。 |
| 修改文档标题和密级 | 支持 | 支持 | 不支持 | 修改后进入操作审计。 |
| 删除文档 | 支持 | 支持 | 不支持 | 删除文档时同步删除知识片段。 |
| 重新索引 | 支持 | 支持 | 不支持 | 重新解析并切分文档。 |
| 查看公开/内部资料 | 支持 | 支持 | 仅问答使用 | 普通员工不能进入文档管理，只能通过问答工作台获得授权范围内的回答。 |
| 查看敏感资料 | 支持 | 支持 | 不支持 | 检索、问答、文档列表均按权限过滤。 |
| 用户管理 | 支持 | 不支持 | 不支持 | 新增用户、改角色、启用/禁用、重置密码。 |
| 操作审计 | 支持 | 不支持 | 不支持 | 记录上传、修改、删除、用户变更等动作。 |
| 问答工作台 | 支持 | 支持 | 支持 | 普通员工唯一可见、可使用的业务页面；普通员工不展示引用片段栏和置信度指标。 |

## 知识库与问答

| 模块 | 功能点 | 实现说明 |
| --- | --- | --- |
| 文档入库 | 文件解析 | 根据扩展名调用 Markdown/TXT、PDF、DOCX 解析逻辑。 |
| 知识切分 | 文本分块 | 按段落和长度切分为可检索片段。 |
| 中文检索 | jieba + 单字兜底 | 兼顾中文分词和短词查询。 |
| 片段排序 | 字段加权 BM25 + 可选 Embedding + 本地重排 | 以正文 70%、标题 30% 计算关键词分数，再融合语义和重排分数返回 Top-K。 |
| 向量补建 | 批量索引 | 为已有文档补建或更新 Embedding，保存模型和索引状态。 |
| 依据覆盖拒答 | 关键条件覆盖率 | 核心条件未被 Top-K 依据覆盖时拒绝生成，并记录缺失词。 |
| 可信回答 | 引用约束 | 回答只基于命中文档片段生成，置信度低时拒绝编造。 |
| 引用溯源 | 右侧引用栏 | 管理员可查看来源文档、片段编号、相似度和片段内容，支持展开与跳转查看；普通员工仅查看回答正文。 |
| 检索调试 | 独立 Top-K 页面 | 用于展示权限过滤、检索效果、命中词和排序解释，适合答辩演示。 |
| 文档版本 | 版本历史 | 文档上传、标题/密级变更和重索引会记录版本号、操作类型、片段数和操作者。 |
| 知识缺口 | 低置信问题闭环 | 将低置信度问题标记为待补充知识，支持处理中、已解决状态和处理备注。 |
| 健康体检 | 知识库治理评分 | 根据文档结构、片段数量、低置信问答和知识缺口生成健康分、风险文档和优化建议。 |
| 问答反馈 | 员工反馈闭环 | 员工可标记回答有用、无用或需补充，负向反馈自动生成知识缺口。 |
| Agent 任务 | 异步执行与治理 | 任务立即返回编号，支持持久化状态、幂等提交、协作式取消、失败重试和用户隔离。 |

## 安全与评测

| 模块 | 功能点 | 实现说明 |
| --- | --- | --- |
| Prompt 注入防护 | 问题检测 | 对“忽略规则、泄露密钥、输出全部资料”等危险意图进行拦截。 |
| 敏感信息脱敏 | 回答和引用脱敏 | 对密钥、连接串、手机号、身份证号、银行卡号、合同金额等信息进行替换。 |
| 问答日志 | 审计记录 | 记录问题、回答、置信度、拦截原因、引用来源和用户。 |
| 单条评测 | 关键词命中 | 根据期望关键词和回答置信度计算质量得分。 |
| 检索评测 | Recall@K + MRR | 判断正确来源是否召回以及首次命中的排序位置。 |
| 批量评测 | 答案与拒答准确率 | 分别验证应回答问题和无依据问题的行为。 |
| 版本化黄金集 | 稳定键 + SHA-256 指纹 | 黄金用例随代码评审，运行内容可识别、可复现且不可在界面误改。 |
| 质量门禁 | 阈值 + 批准/历史基线 | 同时阻止绝对指标不达标和单项回退超过 5 个百分点；CI 基线随代码评审。 |
| CI 评测 | 失败退出码 + JSON 产物 | GitHub Actions 在代码测试后运行确定性评测并保留机器可读报告。 |
| 报告导出 | Markdown/CSV | 评测结果可直接用于论文测试章节。 |
| 健康报告导出 | Markdown/CSV | 知识库健康体检结果可导出为治理报告。 |

## 可视化与体验

| 页面 | 展示内容 |
| --- | --- |
| 首页总览 | 文档数、片段数、用户数、模型状态、文档分布、问答趋势、最近问答、最近批量评测。 |
| 问答工作台 | 管理员视角展示问题输入、回答、置信度、安全拦截提示和右侧引用栏；普通员工视角仅保留简洁问答和常用问题快捷入口。 |
| 智能体工作台 | 提交异步任务、轮询状态、取消运行、重试失败任务，并查看计划和工具调用时间线。 |
| 文档管理 | 文档上传、筛选、搜索、标题/密级编辑、片段查看和版本历史。 |
| 评测中心 | 黄金集版本与指纹、门禁状态、失败指标、基线差异、自定义用例和报告导出。 |
| 检索调试 | Top-K 片段、BM25/Vector/Rerank 分数、问题词项、命中词和权限过滤说明。 |
| 知识缺口 | 低置信问题沉淀、状态流转、处理备注和闭环跟踪。 |
| 健康体检 | 知识库健康分、核心指标、风险文档、低置信样本、缺口状态和治理建议。 |
| 反馈中心 | 员工问答反馈、负向反馈、关联知识缺口和处理线索。 |
| 用户管理 | 管理员可进行用户创建、角色修改、禁用启用、密码重置。 |
| 审计日志 | 问答记录和安全拦截记录。 |
| 操作审计 | 管理员查看管理动作记录和变更详情。 |
