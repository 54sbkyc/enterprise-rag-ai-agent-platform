# v1.8.0 - Realistic RAG Benchmark Release

`v1.8.0` 将原有 12 条演示级黄金集升级为可审计的 50 条企业 RAG 基准，并修复中文证据覆盖、正常安全问题误拦截、受限主题误判和拒答引用泄漏等真实问题。

## 核心变化

- 黄金集 v3 包含 42 条可回答用例和 8 条越权、无依据或 Prompt 注入拒答用例，覆盖 easy、medium、hard 三档难度。
- 用例按精确事实、多约束、多文档、同义改写、冲突消解、引用溯源、访问控制和安全拒答标注能力标签。
- 答案从“命中一半关键词”升级为全部事实组断言，并增加禁答词、替代来源组、禁用文档和最小引用数量。
- 门禁新增答案完整度、引用忠实度和安全断言准确率，默认最少用例数从 10 提升到 40。
- 每次批量评测持久化生成模式、模型、Prompt 版本、Token、估算成本、耗时，以及按难度、分类和能力的分层指标。
- Markdown、CSV、API 和现有评测中心统一展示新指标与执行证据。

## 运行时修复

- 中文关键条件覆盖改为基于分词的语义词覆盖，短问题采用更严格的自适应阈值。
- 问题中的年份和数字作为硬条件，证据未覆盖时必须拒答。
- “密码要求”和“账号泄露处置”等正常制度问题不再被简单敏感词误拦；带索取或导出意图的密钥请求仍会阻断。
- 受限主题同时使用标题语义覆盖和显式别名策略，降低普通办公问题误判并阻止低权限敏感查询。
- 证据不足或低置信拒答不再返回近似引用，避免把不支持结论的片段呈现成依据。

## 验证结果

- 175 项 pytest 自动化测试通过；2 项真实 pgvector PostgreSQL 测试由 CI 专用任务执行。
- 确定性本地基准：50/50 用例通过。
- Recall@K `100%`，MRR `0.9544`。
- 答案正确率、拒答准确率、访问控制准确率、引用忠实度和安全断言准确率均为 `100%`。
- 批准运行记录 `28,260` 个估算 Token，估算成本 `$0`，本机平均耗时 `11.60 ms`；耗时只作为环境快照，不作为跨机器承诺。
- 批准基线指纹：`8fd2de0c38975e89b315f3d417acab247a36e4964d726be26c3842cd59251a22`。

## 诚实边界

- 当前批准基线验证仓库内置 15 份脱敏样例文档和确定性本地抽取模式，不代表任意企业语料或外部大模型的通用准确率。
- Token 为本地估算值；接入模型供应商时优先记录供应商返回值，成本依赖环境变量中的价格配置。
- v1.8 仍使用 SQLite 保存业务事实；持久化多进程任务队列和 PostgreSQL 业务库属于后续版本。
