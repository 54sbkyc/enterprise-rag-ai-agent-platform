# v1.2.0 - Role-Aware RAG Security Release

`v1.2.0` 将项目从“可演示的 RAG + Agent 应用”推进为“可用角色化数据证明安全与质量不退化的 AI 应用作品集”。本版本重点解决 Agent 长任务可靠性、RAG 回归门禁和低权限错误回答三个真实工程问题。

## 核心变化

- **角色化 RAG 门禁**：12 条黄金用例分别以管理员、技术员工和普通员工执行，覆盖可回答、越权拒答与无依据拒答。
- **访问控制指标**：新增访问控制准确率；任何引用超出执行角色允许密级都会让门禁失败。
- **受限主题拒答**：低权限问题强匹配不可访问文档标题时，在读取正文和普通范围检索前返回通用拒答，避免从相似公开资料拼接错误答案。
- **版本化质量治理**：黄金集、SHA-256 指纹、批准基线、历史基线、绝对阈值和 5 个百分点回退策略贯通 API、CLI、数据库与界面。
- **可靠 Agent 任务**：支持进程内异步执行、持久化状态、用户级幂等、活动任务上限、协作式取消和失败重试。
- **可复现 CI**：GitHub Actions 在隔离数据库导入公开样例资料，运行 pytest 与确定性 RAG 门禁，并上传 JSON 报告。

## 验证结果

- 129 项 pytest 自动化测试全部通过。
- `enterprise-rag-golden-v2` 的 12 条用例全部通过。
- Recall@K `100%`、MRR `1.0000`、答案正确率 `100%`、拒答准确率 `100%`、访问控制准确率 `100%`。
- 锁定依赖检查、`pip check`、Python 编译、Markdown 链接、忽略规则和疑似密钥扫描通过。
- 桌面与 `390x844` 手机视口验证通过，没有横向溢出。
- 普通员工询问合同审批材料时返回通用拒答，不展示敏感标题、引用或治理入口。

## 生产边界

- SQLite、向量 JSON 和进程内任务执行器适合本地演示、作品集和小规模单实例部署。
- 受限主题预检仅使用不可访问文档标题元数据，不读取受限正文；生产环境仍需 SSO、部门/岗位/文档级 ACL 和集中策略引擎。
- 多实例生产环境应迁移 PostgreSQL + pgvector、独立 rerank、外部任务队列、任务租约、跨实例恢复与人工审批。

详细设计与演进路径见 [RAG 质量门禁](../rag_quality_gate.md) 和 [生产化路线图](../production_roadmap.md)。
