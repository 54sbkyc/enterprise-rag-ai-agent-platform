# v1.1.0 - Practical AI Application Release

`v1.1.0` 是企业知识库 RAG + AI Agent 平台的首个公开作品集版本，重点不是增加页面数量，而是补齐检索、拒答、评测、Agent 可靠性和工程交付闭环。

## 核心能力

- **混合检索**：默认 BM25 + 本地重排；显式配置 Embedding 后融合语义向量召回。
- **可信拒答**：问题关键条件没有被 Top-K 依据覆盖时，系统不会用相似文档强行拼接答案。
- **量化评测**：分别计算 Recall@K、MRR、答案正确率和拒答准确率。
- **受控 Agent**：支持确定性或可选模型规划，工具调用受白名单、权限、超时和重试约束。
- **AI 可观测**：保留检索分数、引用、决策轨迹、Token、成本和 Agent 工具耗时。
- **企业安全**：具备角色权限、文档密级、Prompt 注入拦截、敏感信息脱敏和审计日志。

## 快速运行

```powershell
.\start.ps1
```

启动后打开脚本输出的本地地址，使用 `admin / admin123` 体验完整治理功能，或使用 `employee / user123` 检查普通员工权限边界。

完整演示步骤见 [AI 应用演示脚本](../demo_runbook.md)。

## 验证结果

- 113 项 pytest 自动化测试通过。
- GitHub Actions 在全新环境安装依赖并运行完整测试。
- Playwright 已验证检索分数拆解、Agent 计划与耗时、批量评测、关键条件拒答和移动端导航。
- 远端发布树不包含数据库、上传文件、毕业设计 Word、缓存、密钥或本地隧道工具。

## 生产化边界

当前版本是可复现的 AI 应用作品集，不冒充大型企业生产系统。向量仍保存在 SQLite，Agent 仍同步执行，真实生产环境应升级 PostgreSQL + pgvector、独立 rerank、异步任务队列、部门级 ACL、SSO、集中 tracing 和密钥托管。

详细演进计划见 [生产化路线图](../production_roadmap.md)。
